这版把「Pi 怎么被启动」整个换了一遍，也终于能看见并点掉「有没有新版」。两个包都是 Windows x64。

## 新功能

- **执行代理**：Pi 不再由后台服务直接起。服务跑在系统账户下，拿到的环境、凭据、窗口站跟桌面上不是一回事；现在由登录会话里的代理进程代起，跑的就是你自己的环境。代理没连上时界面会说清楚，不会偷偷退回系统账户去跑。Control 启动时要管理员权限（注册登录任务需要），代理本身用普通权限。
- **设备配对**：一张设备令牌就能加设备，Control 里点「添加设备」出二维码，扫完直接连，每台设备可以单独作废。
- **更新提示与一键升级**：启动后 20 秒查一次 Pi 与扩展有没有新版，之后每 6 小时。有新版时输入框上方一条提示、侧栏「扩展」带标记、设置页「运行时」卡片写明版本。点「升级」经执行代理跑 `pi update`，进度是一张卡片从「进行中」翻成结果；装不上就留在原来那个版本，不用你手动退回。
- **字号设置**：设置页把正文、过程区、界面分成三块，各四档。放大之后按钮、标签、输入框跟着长，不会夹字。
- **路径右键菜单**：正文里的路径右键可以「打开」「打开所在目录」「复制路径」「复制文件」。
- **过程区重做**：一轮里「干活 → 回答 → 再干活」分成段；点一行就地展开它的完整内容；整块只有一个滚动框，往上翻时浮出「回到最新」。

## 问题修复

- **切会话时图片附件会跟过去**：在 A 里贴的图，切到 B 还挂在输入框上方，一回车就发到 B 去了。现在附件和文字草稿一样按会话存。
- **流式输出时画面在抖**：重画不再无条件拽到底部（只有原来贴着底才跟随）；代码块的「复制」按钮也不再一闪一闪。
- **展开的步骤被新步骤收起**：现在只往后追加，展开的那条按「段 + 步骤」找回来。
- **并行调用时非末行一直转圈**：原来只刷新最后一行，中间那几行看着像卡住。
- **空白思考画成空步骤**：只有空格的 thinking 不再占一步。
- **压缩上下文后丢历史**：对话改成按「角色 + 时间戳 + 调用」合并写入，不再整段替换。
- **关服务卡在「停止中」**：关闭时先把连接全断开，不再等 WebSocket 超时。
