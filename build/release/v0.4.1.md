这版主要改对话本身：说话时不用等、干活时能接着排队，界面上的状态也终于说实话了。两个包都是 Windows x64。

## 新功能

- **追加输入**：干活时按回车不再打断这一轮，话先排进输入框上方的清单，可以改、可以删，这一轮结束后依次送出去。
- **发送立刻可见**：按回车的那一刻消息就出现在对话里，同时切进工作状态，不用等后台确认。
- **发送状态**：气泡左边一个小圈，送达后淡出；没发出去时变成红色感叹号，点它可以重新发送或删掉这条。
- **正文里的地址与路径可点**：网址点开浏览器；像 `E:\Dev\SevenStation` 这样的绝对路径点一下就在资源管理器里打开，文件会直接选中。
- **对话区改版**：自己的消息右对齐并着色，输入区多留白、带常驻阴影，执行步骤只留最新一条，滚动贴着底部才跟随。
- **通知换位置**：临时提示落在正文与输入框之间的留白里；压缩、停止这类要等结果的操作是一条卡片，从「进行中」翻成结果，不再开始弹一条结束弹一条。

## 问题修复

- **侧栏「工作中」时有时无**：原来只在增删改名时刷新列表，干活开始和结束都不推，所以转圈经常缺。
- **模型显示与清单**：新对话没选过模型时原来显示成清单第一条（GLM-5.2），现在显示 Pi 真正在用的默认模型；清单缓存也不再永不过期，24 小时自动重取，面板底部可手动刷新。
- **按停止后排队的内容自己发出去**：停止就是停止，排队的话留在面板里等你决定。

两个包都可以覆盖装 0.4.0：Seven Station Core 的数据在 `%ProgramData%\SevenStation.Core`，客户端的连接信息在 `%LOCALAPPDATA%\SevenStation\center.json`，配置、令牌、对话库都保留。

完整实现与验收记录见 [进度记录](https://github.com/huaxianyan/SevenStation/blob/v0.4.1/docs/STATUS.md)。
