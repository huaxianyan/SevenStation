# 过程区折叠规则：现状与交接说明

这份文档是给要改「过程区（工作块）自动折叠」的人看的。2026-11-23 用户决定这部分交给他自己开发，
做完提 PR 合并。这里把现状、冲突点、必须保持不变的东西写清楚，省得来回问。

改动只在 `src/SevenStation.Core/wwwroot/` 里，纯原生 HTML/CSS/JS，没有构建步骤。

## 现在的行为

一轮对话里可能有「工作 → 正文 → 工作 → 正文」好几段。相关代码在 `wwwroot/app.js`：

| 位置 | 做什么 |
| --- | --- |
| `turnParts(turn)` | 把一轮切成按顺序的 `segments`，空白思考会被过滤掉 |
| `turnNode()` | 逐段画；`const live = streaming && index === segments.length - 1` 决定哪一段是「还在跑的最后一段」 |
| `workGroup(work, collapsed, …)` | `collapsed = !live`：**跑着展开，一旦不是最后一段就收起** |
| `ui.work` | 用户手动点开/收起过的段记在这里，键是 `turnKey#段序号`；有记录时以记录为准，不会被自动切换覆盖 |

也就是说：**只有正在跑的最后一段默认展开**，别的段一律收起；唯一豁免是用户亲手点过的那一段。

用户反馈的原话是「一段工作正展开显示，模型接着输出正文或新步骤，这一段立刻收起」——这在当前规则下是预期行为。

## 冲突在哪

三条需求互斥：

- **A**：跑的时候要能看见在干什么 → 需要默认展开；
- **B**：跑完要收起 → 不然过程区把正文顶走、一轮拉得很长（0.5.0 分段就是为这个）；
- **C**：用户正在读的那一段不能被抽走。

B 和 C 直接对立。判定「正在读」只有两个信号：手动点过（已有），或者它正在视口里（还没用）。

## 候选方案（择一或自拟）

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| A 现状 | 默认收起，手点过就粘住 | 0 |
| B 视口判定 | 段在视口里不收，滚出去才收（IntersectionObserver + 重画后复原） | 中等；要和「贴底跟随」协调，否则会「一边滚一边收」抖 |
| C 只收更早的 | 最近一段已完结的保持展开，新段出现时再收上一段 | 小 |
| D 永不自动收起 | 跑完不收，用户自己收 | 0，但长轮次很吵 |

选哪个由你定。只要满足下面的不变量，实现方式不限。

## 必须保持的不变量

这些是过去几个月一个一个 bug 换来的，改折叠时很容易顺手弄坏：

1. **过程区只能有一个滚动框**：`.work-body`。详情（`.st-more`）和里面的输出块都不能自己 `overflow`——
   以前是四层各滚各的，滚轮滚到哪儿全靠猜。限高是 `min(48vh, 340px)`。
2. **贴底才跟随**：过程区自己滚动时，只在用户贴着底时才跟随新步骤；用户往上翻就冻住，并浮出
   「回到最新（n 条）」。滚动位置与「贴不贴底」存在 `workScroll`（按 `turnKey`，上限 200 条），
   整轮重画后用 `requestAnimationFrame` 复原。
3. **重画不能重置动画**：过程区每来一条事件都可能重画那一行甚至整轮。状态节点内容没变就不要
   `replaceWith`（`sameState()`）；新建转圈节点要用负的 `animation-delay` 把相位钉到墙上时钟（`spinPhase()`），
   否则事件一密就看着像卡住不转。
4. **步骤详情就地展开、要能找回来**：点一行在它下面展开这一条，Esc 或再点收起，同时只开一条。
   整轮重画后靠 `restoreOpenDetail()` 按「段键 + 步骤 id」找回展开状态；新步骤进来只能往后追加，
   别整组 `innerHTML = ''`。
5. **`renderThread()` 不要无条件拽到底**：同一会话重画只在原来贴底时才跟随，换会话才强制到底
   （`app.renderedKey`）。`atBottom()` 的阈值是 24 px。
6. **折叠状态存 app 层，键带段序号**（`turnKey#序号`）：DOM 上的类名会在重画时消失，
   只存在 DOM 上的状态等于没有。
7. **工作时只渲染最新一条步骤**：`patchItem()` 对「在跑且还没有正文」的那一轮走就地更新，只改文字节点。

## PR 边界

- 只改 `src/SevenStation.Core/wwwroot/` 下的 `app.js`、`styles.css`、`index.html`，以及 `scripts/ui-tests/` 里的测试。
- 不要改 `src/SevenStation.Core` 里的 C#（折叠纯前端，不涉及存储与 RPC）；不要改数据库字段。
- 不要引入依赖、构建步骤或框架，保持原生 JS。
- 字号一律写 `calc(原值px * var(--fs-区域))`（`body` / `work` / `ui` 三档），不要写死 `font-size: 13px`。
- 放大字号不能夹字：固定 `height` 改成 `min-height`，该截的地方才用省略号且必须带 `title`。
- 强调色（`--accent`）只用于导航选中、发送键、开关这类小面积，别拿去染过程区。
- 提 PR 时说明选了哪个方案、为什么，以及新增/修改了哪些断言。
