这版把「Pi 怎么被启动」整个换了一遍，也终于能看见并点掉「有没有新版」。两个包都是 Windows x64。

## 新功能

- **执行代理**：Pi 不再由后台服务直接起。服务跑在系统账户下，拿到的环境、凭据、窗口站跟桌面上不是一回事；现在由登录会话里的代理进程代起，跑的就是你自己的环境。代理没连上时界面会说清楚，不会偷偷退回系统账户去跑。Control 启动时要管理员权限（注册登录任务需要），代理本身用普通权限。
- **设备配对**：一张设备令牌就能加设备，Control 里点「添加设备」出二维码，扫完直接连，每台设备可以单独作废。
- **更新提示与一键升级**：启动后 20 秒查一次 Pi 与扩展有没有新版，之后每 6 小时。有新版时输入框上方一条提示、侧栏「扩展」带标记、设置页「运行时」卡片写明版本。点「升级」经执行代理跑 `pi update`，进度是一张卡片从「进行中」翻成结果；装不上就留在原来那个版本，不用你手动退回。
- **字号设置**：设置页把正文、过程区、界面分成三块，各四档。放大之后按钮、标签、输入框跟着长，不会夹字。
- **路径右键菜单**：正文里的路径右键可以「打开」「打开所在目录」「复制路径」「复制文件」。
- **过程区重做**：一轮里「干活 → 回答 → 再干活」分成段；点一行就地展开它的完整内容；整块只有一个滚动框，往上翻时浮出「回到最新」。
- **模型面板多了「常用」**：左栏第一项不再是把所有模型堆在一起的「全部」，而是你最近选过的 7 个，最新的排最上面；再选一个已经在里面的，它就回到顶部。名单存在 Seven Station Core 里，桌面和手机看到的是同一份。要找别的模型，点对应的 provider 或直接搜。
- **升级完 Pi，不用新开对话**：以前升级只改了磁盘上的版本指针，已经起来的对话还是老代码，只能靠「新开对话」用上新版本。现在每次发消息前对一眼版本，不一致就悄悄重起（上下文接着原来那段）。另外点升级时如果有对话正在跑，会先问一句「停下并升级 / 等它跑完」——以前是直接拒绝。
- **文件面板的头部改了**：以前「上一层」在左、「关闭」在最右，一手滑就把面板当成「返回」按了。现在左边一组是 `× 关闭` 与 `↑ 上一级`，路径在右边并且可以点——点哪一段就回到那一级。已经在工作区根时，向上的按钮是灰的。
- **看得见 git 分支**：输入框那一行多一颗分支胶囊，工作区是仓库时出现，带改动数、领先/落后；点开能看到当前分支、本地分支和改动清单（只看不改，切分支还是走命令）。宽度不够时先收目录名——它在上方面包屑和左侧列表里都看得到，分支只在这一处有。

- **会话列表与用量会自己走了**：以前列表里那一格时间只在收到新列表时重算，正在跑的那条永远写着开始前的时间；tokens 与上下文占比也要等一轮结束才更新。现在在跑的那条写「工作中」，其余每 30 秒自己走过去；用量在干活过程中也会跟着刷新（右上角那行与输入框那颗圆是同一次渲染，永远一致）。

- **记住上次的模型与思考等级**：新建对话沿用上一次用的模型和思考等级（以前每次都回到最低那档，而 Pi 其实跑的是它自己的默认值，两边对不上）。
- **输入区那行只留三样**：模型、思考等级、git 分支。工作区不再重复一遍——左侧列表和上方面包屑里都有。
- **长跑的时间写成小时**：「工作 30620 秒」现在写「工作 8 小时 30 分」，超过一天写「1 天 3 小时」。
- **卡住了看得出来**：Pi 卡在某个不返回的工具上时，以前界面会一直显示「工作中」、只有秒数在涨。现在 3 分钟没有输出就写「3 分没动静」，10 分钟以上写「可能卡住了」。按停止之后也不再报时长。

## 问题修复

- **切会话时图片附件会跟过去**：在 A 里贴的图，切到 B 还挂在输入框上方，一回车就发到 B 去了。现在附件和文字草稿一样按会话存。
- **流式输出时画面在抖**：重画不再无条件拽到底部（只有原来贴着底才跟随）；代码块的「复制」按钮也不再一闪一闪。
- **展开的步骤被新步骤收起**：现在只往后追加，展开的那条按「段 + 步骤」找回来。
- **过程区两处误报**：并行调用时中间几行一直转圈（原来只刷新最后一行）；只有空格的 thinking 被画成一个空步骤。
- **压缩上下文后丢历史**：对话改成按「角色 + 时间戳 + 调用」合并写入，不再整段替换。
- **正文里的相对路径点不了**：Agent 提到文件时写 `docs/STATUS.md` 这种相对路径，界面上只是一串死文字。现在会按会话工作目录补成完整路径；说中文这条也补强了，调用工具前的说明同样是中文。
- **关服务卡在「停止中」**：关闭时先把连接全断开，不再等 WebSocket 超时。
- **还在跑的时候侧栏却不转了**：Pi 报「一次底层运行结束」时，重试、上下文压缩、追加输入这些都可能还在后面继续跑，我们原来就在那一刻把「工作中」放掉了——侧栏安静了，回答却还在往外冒。现在以「Pi 不会自己继续了」为准。另外服务重启过（装包就是）之后，界面里那条对话也不会再挂着上一轮的「正在跑」。
- **第一次点开对话看不到分支胶囊**：要切走再切回来才出现。现在打开那一刻就问。
- **装成服务之后 git 完全读不到**：服务账户读别人名下的仓库会被 git 拒掉（`detected dubious ownership`），原因只写在它丢弃的那一路输出里，所以日志里一条都没有。现在会带上放行配置，读不到时也会留一行原因。

两个包都可以覆盖装：Seven Station Core 的数据在 `%ProgramData%\SevenStation.Core`，客户端的连接信息在 `%LOCALAPPDATA%\SevenStation\center.json`，配置、令牌、对话库都保留。
